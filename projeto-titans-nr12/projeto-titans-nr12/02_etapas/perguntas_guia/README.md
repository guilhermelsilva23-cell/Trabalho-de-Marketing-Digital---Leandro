## Como ler cada pergunta

| Campo | Significado |
|---|---|
| **Lente** | P = profissional (muda uma decisão ou peça da Titans) · A = acadêmica (testa hipótese ou fundamenta o método) · P+A = as duas |
| **Quem responde** | Titans (via professor), Grupo (pesquisa), Mercado (entrevistas), Norma (texto vigente) |
| **Evidência mínima** | O que precisa existir para a pergunta contar como respondida. Sem isso, a resposta entra como **[H]** ou **[L]**, conforme `00_gestao/fontes_e_validacao.md` |
| **Alimenta** | Etapa, hipótese ou entregável do PDF que depende da resposta |
| ★ | Pergunta bloqueante |

## Regra de fechamento

Uma etapa só vira "desenvolvida" quando as perguntas ★ têm resposta com evidência ou foram registradas como lacuna em `00_gestao/decisoes.md`.

## Fluxo de trabalho no Git

1. Responder a pergunta no arquivo da etapa, marcando o **Status**.
2. Se virar fato, incluir a linha em `00_gestao/fontes_e_validacao.md`.
3. Se virar decisão, registrar em `00_gestao/decisoes.md`.
4. Anotar a data e o que foi feito em `00_gestao/diario_de_bordo.md`.
