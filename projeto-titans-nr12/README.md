## Legenda de tipos de evidência (vale para todo o repositório)
| Código | Significado | Peso no artigo |
|---|---|---|
| **[F]** | Fato com fonte documental (norma, portaria, estatística) | Pode sustentar afirmação |
| **[E]** | Relato de especialista (prof. Leandro, Titans) | Fonte primária qualitativa; não vira dado de mercado |
| **[H]** | Hipótese a validar | Não usar como afirmação |
| **[S]** | Resultado de simulação exploratória (agentes de IA) | Só gera hipóteses e testa mensagens; nunca prova |
| **[L]** | Lacuna de dado | A coletar |
